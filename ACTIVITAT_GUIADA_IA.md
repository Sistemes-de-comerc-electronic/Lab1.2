# Activitat guiada amb IA - Lab 1.2

Aquest repositori és el punt de partida per practicar Symfony, rutes, Twig i una primera connexió amb base de dades. La IA us pot ajudar, però heu de guiar-la amb context i criteris de verificació.

## Què heu de fer

1. Demaneu a la IA un pla per crear i executar un projecte Symfony local.
2. Feu un prompt per crear un controlador i una ruta `/hello/demo`.
3. Feu un prompt per retornar una vista Twig i passar-hi variables.
4. Feu un prompt per configurar Doctrine i connectar una entitat `Car` amb una taula MySQL.
5. Feu un prompt de depuració si fallen la ruta, la plantilla, la variable Twig o la connexió a BD.

## INPUTS per Moodle

- Prompt inicial amb eines, carpeta de treball, ruta esperada i objectiu.
- Prompt final per controlador + Twig.
- Prompt per entitat + BD, amb preguntes de seguiment.
- Error trobat, prompt de depuració i comprovació aplicada.
- Reflexió final sobre què heu après a especificar millor.
